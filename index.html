Panduan Langkah Instalasi

1

Klik Tombol Install / Download

Untuk Tampermonkey Script: klik tombol Install pada modul yang diinginkan. Tab baru akan terbuka otomatis.
Untuk Chrome Extension: klik Download, lalu extract file .ZIP yang terunduh.

2

Konfirmasi di Tampermonkey / Chrome

Untuk Script: Tampermonkey akan menampilkan konfirmasi install, klik "Install".
Untuk Extension: Buka chrome://extensions, aktifkan Developer Mode, lalu klik "Load Unpacked" dan pilih folder hasil extract.

3

Selesai — Siap Digunakan!

Script atau Extension langsung aktif. Buka LiveChat dan fitur otomatisasi akan berjalan secara real-time.
